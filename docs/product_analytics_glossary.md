# Product Analytics Glossary

- **Activation**: first moment a user reaches the core value of the product.
- **Cohort**: users grouped by a shared start period such as signup week.
- **Conversion**: percentage progressing from one step to another.
- **Engagement**: repeated meaningful interaction with the product.
- **North-star metric**: single metric most aligned with long-term product value.
- **Retention**: whether users come back after first use.
- **Safety event**: moderation, spam, abuse, or trust-related signal.
- **Session**: one continuous period of app usage.
- **Vanity metric**: metric that looks large but does not explain product value.
